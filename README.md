# 매일 공부 스탬프

매일(또는 정해진 주기로) 목표를 달성했는지 캘린더에 체크하며 기록하는 정적 웹앱입니다.
순수 HTML/CSS/JavaScript로만 만들어져 있어 별도 서버 없이 GitHub Pages에서 바로 동작합니다.

## 폴더 구성

- `index.html` — 로그인, 캘린더, 설정 화면 마크업
- `style.css` — 전체 스타일
- `app.js` — 앱 로직 (데이터 저장, 화면 렌더링, 이벤트 처리)

## 데이터 저장 방식

서버 없이 동작하므로 모든 데이터(사용자, 목표, 완료 기록)는 **접속한 기기의 브라우저 localStorage**에 저장됩니다.
따라서:

- 같은 브라우저에서는 새로고침해도 데이터가 유지됩니다.
- 다른 기기/다른 브라우저에서 접속하면 별도의 저장 공간을 사용하므로 데이터가 공유되지 않습니다. 여러 사람이 같은 데이터를 보게 하려면 모두 **같은 브라우저(같은 기기)**로 접속해야 합니다.
- 브라우저 저장 데이터를 지우면(캐시 삭제 등) 기록도 함께 사라집니다.

## 기능 요약

1. **로그인**: 4자리 코드(영문+숫자 혼합 가능)로 사용자를 구분합니다. 최초 관리자 코드는 `a111`입니다.
2. **좌측 내비게이션**: 로그인 후 화면 왼쪽에 캘린더 / 현황판 / 설정 / 로그아웃 메뉴가 항상 표시됩니다.
3. **캘린더(메인 화면)**: 상단에 "이번 달 내 달성률" 카드(달성률 %, 완료한 목표 수, 연속 달성일)가 표시됩니다. 아래에는 월 단위 캘린더가 표시되며, 날짜를 클릭하면 그 날짜에 해당하는 목표 목록이 열립니다. 체크 후 "완료 저장"을 누르면 기록됩니다. 완료된 날은 초록색으로, 일부만 완료된 날은 주황 점으로 표시됩니다.
4. **현황판**: 모든 참여자의 이름, 월별 달성률(월 이동 가능), 연속 목표 달성일수를 한 화면에서 확인할 수 있습니다. 목표(또는 계정)가 해당 월 중간에 생성됐다면 그 생성일부터의 날짜만 달성률 계산에 포함됩니다(그 이전 날짜는 분모에서 자동 제외).
5. **설정 화면**: 좌측 내비게이션의 "⚙️ 설정" 메뉴로 이동합니다.
   - **목표 추가**: 매일 / 주간(요일 선택) / 사용자 지정 주기(N일마다) 중 선택하고, 제목·설명과 "필수 목표 여부"를 입력해 저장합니다. 목표를 다시 눌러 수정·삭제할 수 있습니다.
   - **접속 코드 변경**: 새 4자리 코드로 변경합니다. 변경 즉시 자동 로그아웃되며, 새 코드로 다시 접속해야 한다는 안내가 표시됩니다.
   - **데이터 백업 및 복구**: 내 목표와 완료 기록을 JSON 파일로 다운로드하거나, 저장해둔 파일을 업로드해 복구할 수 있습니다. 복구 시 현재 로그인된 계정의 기존 목표·기록은 백업 파일 내용으로 모두 대체되며, 진행 전 확인 메시지가 표시됩니다. (다른 사람의 데이터가 아닌, 로그인한 본인 계정 데이터만 백업/복구합니다.)
   - **사용자 추가 (관리자 전용)**: 이름과 임시 접속 코드(자동생성 가능)를 입력해 새 사용자를 만듭니다. 새로 발급된 코드는 해당 사용자가 로그인 후 설정에서 직접 변경할 수 있습니다.

## GitHub Pages로 배포하는 방법

1. GitHub에서 새 저장소를 만듭니다. (예: `daily-study-stamp`)
2. 이 폴더의 `index.html`, `style.css`, `app.js` 파일을 저장소 루트에 올리고(업로드 또는 git push) 커밋합니다.
   ```bash
   git init
   git add index.html style.css app.js README.md
   git commit -m "매일 공부 스탬프 초기 배포"
   git branch -M main
   git remote add origin https://github.com/사용자명/daily-study-stamp.git
   git push -u origin main
   ```
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`로 두고, Branch는 `main`(또는 `master`), 폴더는 `/ (root)`를 선택 후 저장합니다.
5. 잠시 후 `https://사용자명.github.io/daily-study-stamp/` 주소로 접속하면 사이트가 열립니다.

## 참고 / 향후 개선 아이디어

- 현재는 기기(브라우저)별로 데이터가 저장되므로, 여러 사람이 각자의 기기에서 같은 기록을 보려면 Firebase 등 별도의 백엔드 연동이 필요합니다. 지금 구조는 "한 기기를 여러 사람이 코드로 구분해서 함께 쓰는" 시나리오(예: 가족 공용 태블릿, 교실 공용 PC)에 맞춰져 있습니다.
- 목표의 "주간" 주기는 특정 요일(예: 월/수/금)을 선택하는 방식이고, "사용자 지정 주기"는 목표를 만든 날짜를 기준으로 N일마다 반복되는 방식입니다.
- 달성률은 "해당 기간 동안 체크했어야 할 목표 수 대비 실제로 체크한 목표 수"로 계산합니다. 미래 날짜와 목표가 하나도 없던 날(계정/목표 생성 이전 등)은 계산에서 제외됩니다.
- 연속 달성일(스트릭)은 오늘부터 거슬러 올라가며 그날의 모든 목표를 완료한 날의 연속 개수를 셉니다. 단, 오늘(또는 목표가 있는 가장 최근 날)이 아직 미완료여도 스트릭이 끊기지는 않고, 그 전날부터 판단합니다.
